# 农业合作社 - 节点超时追踪种植任务系统

基于真实农业合作社办理场景的种植任务全流程管理系统，支持从登记、审核到复核归档的连续处理，按岗位控制权限，按节点计算超时，状态以后端为准。

## 技术栈

- **前端**: SolidStart (SolidJS) - 端口 3008
- **后端**: NestJS (Node.js) - 端口 8008
- **数据库**: SQLite (better-sqlite3 + TypeORM)

## 快速启动

### 1. 启动后端服务

```bash
cd backend

# 安装依赖
npm install

# 创建数据目录
mkdir -p data

# 初始化数据库（创建表 + 种子数据）
npm run seed

# 启动服务
npm run start
```

后端服务启动在 **http://localhost:8008**

### 2. 启动前端服务

```bash
cd frontend

# 安装依赖
npm install

# 启动开发服务
npm run dev
```

前端服务启动在 **http://localhost:3008**

## 业务流程

### 种植任务处理流程

```
[待登记] → 登记提交 → [待审核] → 审核通过 → [待复核] → 复核通过 → [已归档]
                ↓                    ↓                     ↓
            （登记员）           （审核主管）           （复核负责人）
                                 ↗  ↖                    ↗  ↖
                            驳回      补正            驳回      重审
                              ↓        ↑                ↓        ↑
                          [审核驳回]──┘            [复核驳回]──┘
```

### 节点超时规则

| 处理节点 | 责任人 | 超时时限 | 说明 |
|----------|--------|----------|------|
| 种植任务登记 | 种植登记员 | 24 小时 | 从任务创建/驳回重提开始计算 |
| 种植任务审核 | 种植审核主管 | 48 小时 | 从登记提交开始计算 |
| 复核归档 | 复核负责人 | 72 小时 | 从审核通过开始计算 |

### 状态流转

- **待登记 (pending_registration)**: 任务刚创建，等待登记员提交
- **待审核 (registered)**: 登记已提交，等待审核主管审核
- **审核驳回 (audit_rejected)**: 审核未通过，需要登记员补正
- **待复核 (audit_passed)**: 审核通过，等待复核负责人复核
- **复核驳回 (review_rejected)**: 复核未通过，退回审核阶段
- **已归档 (archived)**: 复核通过，任务完成

## 核心功能

### 1. 岗位权限控制

- 不同岗位登录后看到的操作按钮和字段不同
- 登记员：只能创建和登记任务，处理驳回补正
- 审核主管：只能审核任务，填写驳回原因
- 复核负责人：只能复核归档，最终确认

### 2. 节点超时追踪

- 每个任务有三个处理节点，每个节点有独立的时限
- 详情页展示节点进度时间线，标识超时节点
- 列表页支持按"已超时/未超时"筛选
- 统计页展示超时任务数量

### 3. 操作记录

- 每次状态变更都记录操作日志
- 包含操作人、操作类型、操作详情、异常原因
- 详情页可查看完整操作历史

### 4. 异常原因录入

- 推进任务时可录入异常原因
- 驳回时必须填写驳回原因
- 异常原因随操作记录保存

### 5. 数据一致性

- 所有状态变更以后端为准
- 前端操作后重新拉取最新数据
- 刷新页面后列表、详情、统计数据保持一致
- 接口返回明确的错误信息，而非通用失败

## 主要页面

- **登录页**: `/login` - 账号密码登录
- **任务列表**: `/tasks` - 所有种植任务，支持筛选、搜索、分页
- **任务详情**: `/tasks/:id` - 任务详情、节点进度、操作记录、操作按钮
- **新建任务**: `/tasks/create` - 创建新的种植任务（仅登记员）
- **数据统计**: `/statistics` - 任务统计、超时统计、状态说明

## API 接口

### 认证接口
- `POST /api/auth/login` - 登录
- `GET /api/auth/profile` - 获取当前用户信息
- `POST /api/auth/logout` - 退出登录

### 任务接口
- `GET /api/tasks` - 获取任务列表（分页、筛选）
- `GET /api/tasks/statistics` - 获取统计数据
- `GET /api/tasks/:id` - 获取任务详情（含节点、日志）
- `GET /api/tasks/:id/logs` - 获取操作记录
- `POST /api/tasks/create` - 创建任务
- `POST /api/tasks/register` - 提交登记
- `POST /api/tasks/audit` - 审核任务
- `POST /api/tasks/review` - 复核任务

## 开发说明

### 后端开发

```bash
cd backend
npm run start:dev  # 开发模式，热重载
```

### 前端开发

```bash
cd frontend
npm run dev  # 开发模式，热重载
```

### 重置数据库

删除 `backend/data/agriculture.db` 文件，然后重新执行 `npm run seed` 即可。

## 注意事项

1. 必须先启动后端，再启动前端，否则 API 代理会失败
2. 所有接口都需要携带 Bearer Token 进行认证
3. 任务状态只能按流程推进，不能跳节点操作
4. 驳回操作必须填写驳回原因
5. 超时计算基于服务器时间，前端仅做展示
