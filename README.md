# 签约服务单管理系统

社区卫生服务中心家庭医生签约服务单管理演示系统。

## 版本历史

### v2.0 - 登记员发起/补正链路增强 (第二阶段)

**前端增强 - Fresh Islands 可水合交互**

- ✅ **新增签约服务单页面** (`/contract/new`): 登记员可创建新签约单，表单包含居民信息、风险等级等完整字段，高/中风险自动缩短处理时限
- ✅ **服务内容编辑组件** (`ContentEditor.tsx`): 各阶段服务内容可在线编辑，仅登记员在 DRAFT/NEEDS_CORRECTION 状态且当前阶段可编辑，使用 `@preact/signals` 的 `useSignal` 支持 SSR
- ✅ **证据材料管理组件** (`EvidenceManager.tsx`): 支持添加/删除证据，自动识别必需证据（匹配各阶段必填清单），显示必需证据数量统计，添加必需证据后自动提示"必填证据已齐全"
- ✅ **乐观锁版本控制**: 所有编辑操作携带版本号，后端检测冲突并返回友好提示

**后端增强 - 五层校验与风险动作规则**

- ✅ **创建接口校验**: 仅登记员可创建，必填字段校验，风险等级自动设置处理时限（高风险3天/中风险5天/低风险7天）
- ✅ **更新接口校验**: 五层校验（处理人、角色、状态、版本、权限），风险升级自动缩短时限，变更内容完整记录
- ✅ **补正提交校验**: 退回补正后重新提交需重新校验必填证据，高风险补正时限自动缩短
- ✅ **版本冲突检测**: 所有写操作携带版本号，冲突时记录 `STATUS_CONFLICT` 操作日志，保留原状态
- ✅ **证据操作校验**: 仅登记员可管理当前阶段证据，添加证据自动识别是否为必需项，删除证据同步更新计数

**数据增强 - 完整链路与冲突样例**

- ✅ **70条操作日志**: 覆盖创建、编辑、提交、审核、退回、补正、归档等全流程
- ✅ **补正完整链路样例**:
  - 马明玉（高风险）: 签约阶段退回补正完整链路（10条操作日志）
  - 苗翠花: 服务计划阶段退回补正完整链路（9条操作日志）
  - 方大同: 履约确认阶段补正后提交复核完整链路（14条操作日志）
- ✅ **状态冲突样例** (QY202606220016): 版本冲突演示操作日志（5条）
- ✅ **操作记录同步字段**: 状态、上一处理意见、优先级、冲突标记完整保存

## 核心功能

### 业务流程

```
家庭医生签约 → 服务计划 → 履约确认
```

每个阶段都需经过：**登记员提交 → 审核主管/复核负责人办理**

### 角色与权限

| 操作 | 登记员 | 审核主管 | 复核负责人 |
|------|:-----:|:-------:|:---------:|
| 创建签约单 | ✅ | - | - |
| 提交审核 | ✅ | - | - |
| 补正重提 | ✅ | - | - |
| 审核通过 | - | ✅ | - |
| 退回补正 | - | ✅ | ✅ |
| 不予通过 | - | ✅ | - |
| 复核归档 | - | - | ✅ |

### 风险分级与动作规则

风险等级不仅是标签，还会**动态改变队列优先级和触发特殊处理动作**：

| 风险等级 | 基础优先级分 | 处理时限 | 特殊动作规则 |
|---------|:-----------:|:--------:|-------------|
| **高风险 (红色)** | 100 | **3天** | ✅ 创建时自动缩短时限至3天<br>✅ 风险升级时自动缩短剩余时限<br>✅ 队列最优先排序<br>✅ 补正重提后时限自动缩短 |
| **中风险 (黄色)** | 50 | **5天** | ✅ 创建时设置5天时限<br>✅ 正常优先级排序 |
| **低风险 (绿色)** | 10 | **7天** | ✅ 创建时设置7天时限<br>✅ 优先级最低 |

**优先级评分公式**：
```
优先级评分 = 风险基础分 + 时限紧迫度 + 状态权重
```
- 时限紧迫度：剩余时间越短分数越高（逾期+100，剩1天+50，剩3天+20）
- 状态权重：退回补正+30，待办理+10，草稿+0

队列按优先级分数从高到低排序，确保高风险、逾期、退回补正的单据优先处理。

### 提交校验

提交时后端会校验以下内容，不通过则保留原状态并写操作记录：

1. **处理人校验**: 当前用户必须是单据的当前处理人
2. **角色校验**: 用户角色必须与单据当前角色匹配
3. **状态校验**: 当前状态必须允许该操作
4. **版本校验**: 提交版本必须与当前版本一致（乐观锁）
5. **证据校验**: 必填证据数量必须达标

### 操作记录

所有操作都会记录审计日志，包含：
- 操作人、角色
- 操作动作
- 状态/阶段变更前后
- 办理意见
- 版本变化
- 操作时间

| 方法 | 路径 | 说明 |

本系统为纯演示版本，不接外部服务，所有数据存储在本地 SQLite 文件中。

演示时建议按以下路径查看：

#### 登记员视角 (张三，userId=1)
1. **新建签约单**: 访问 `/contract/new?userId=1`，填写居民信息，选择风险等级，观察高/中风险自动缩短时限

5. **补正重提**: 打开 NEEDS_CORRECTION 状态的单据（如 QY202606200002），补正材料后重新提交

3. **上一处理意见**: 在详情页查看登记员提交时的意见和材料

#### 复核负责人视角 (王五，userId=3)
