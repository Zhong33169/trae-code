# 环境检测公司-批量变更复核采样任务系统

## 项目简介

面向环境检测公司的采样任务全流程管理系统，支持从采样登记、审核到复核归档的完整业务闭环，提供批量操作、角色权限控制、版本乐观锁、证据链校验等核心能力。

## 技术栈

- **前端**: React 18 + TypeScript + Vite + Tailwind CSS + TanStack Router/Table/Form + Sonner
- **后端**: Go + Gin + GORM + SQLite
- **数据库**: SQLite（本地文件存储）

## 端口配置

- 前端服务: `http://localhost:3006`
- 后端服务: `http://localhost:8006`
- 数据库文件: `backend/data/app.db`

## 快速开始

### 1. 启动后端服务

```bash
cd backend
go run main.go
```

后端启动后会自动：
- 初始化 SQLite 数据库
- 执行数据库迁移（自动建表）
- 插入种子数据（3个用户 + 8条采样任务 + 对应证据和日志）

### 2. 启动前端服务

```bash
cd frontend
npm install
npm run dev
```

### 3. 访问系统

打开浏览器访问: `http://localhost:3006`

默认以采样登记员角色进入，可在右上角切换角色。

## 业务流程

```
采样登记员创建任务 → 提交审核 → 采样审核主管审核
                                    ↓ 通过          ↓ 驳回
                              待复核（审核通过）   审核驳回（可补正重提）
                                    ↓
                              复核负责人复核
                                ↓ 通过        ↓ 退回
                              已归档        复核退回（可补正重提）
```

## 核心特性

### 三角色权限隔离
- 后一岗位不能替前一岗位补流程
- 每个角色只能执行权限范围内的操作
- 后端中间件严格校验角色权限

### 批量操作
- 支持选中多条任务批量审核/复核
- 逐条处理、逐条返回结果
- 结果分类：成功 / 失败 / 需重试
- 每条结果附带具体原因说明

### 后端强校验
- **角色校验**: 错角色操作直接拦截
- **版本校验**: 旧版本提交返回版本冲突（乐观锁）
- **证据校验**: 审核通过必须有过程核验证据，归档必须有复核证据
- **状态校验**: 不符合当前状态的操作直接拦截

## API 响应格式

所有接口统一返回格式：

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

- `code = 0` 表示成功
- `code != 0` 表示失败，`message` 为错误原因
