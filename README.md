# 环境检测公司-批量变更复核采样任务系统

## 项目简介

面向环境检测公司的采样任务全流程管理系统，支持从采样登记、审核到复核归档的完整业务闭环，提供批量操作、角色权限控制、版本乐观锁、证据链校验等核心能力。

## 技术栈

- **前端**: React 18 + TypeScript + Vite + Tailwind CSS + TanStack Router/Table/Form + Sonner
- **后端**: Go + Gin + GORM + SQLite
- **数据库**: SQLite（本地文件存储）

## 端口配置

- 前端服务: `http://localhost:3006`
- 后端服务: `http://localhost:8006`
- 数据库文件: `backend/data/app.db`

## 快速开始

### 1. 启动后端服务

```bash
cd backend
go run main.go
```

后端启动后会自动：
- 初始化 SQLite 数据库
- 执行数据库迁移（自动建表）
- 插入种子数据（3个用户 + 8条采样任务 + 对应证据和日志）

### 2. 启动前端服务

```bash
cd frontend
npm install
npm run dev
```

### 3. 访问系统

打开浏览器访问: `http://localhost:3006`

默认以采样登记员角色进入，可在右上角切换角色。

```

                │  采样登记员创建任务  │
                │   （草稿状态）      │
                └─────────┬─────────┘
                          │ 提交审核
                          ▼
                ┌───────────────────┐
                │  待主管审核        │
                │ （pending_review） │
                └───────┬───┬───────┘
                        │   │
              ┌─────────┘   └──────────┐
              ▼ 通过                    ▼ 驳回
    ┌───────────────────┐    ┌───────────────────┐
    │ 审核通过待复核     │    │  审核驳回          │

            │   │                      ▼

            │   │              │  补正任务信息  │───┐
            │   │              │  + 补充登记证据 │   │
            │   │              └───────────────┘   │
            │   │                                  │
┌───────────┘   └────────┐                         │
▼ 归档                  ▼ 退回                      │
┌────────────┐    ┌───────────────────┐            │
│  已归档     │    │  复核退回         │            │
│（已完成）   │    │（review_returned）│            │
└────────────┘    └─────────┬─────────┘            │
                            │ 补正+重提              │
                            ▼                      │
                     ┌───────────────┐              │
                     │  补正任务信息  │──────────────┘
```

## 状态定义

| 状态值 | 标签 | 说明 |
|--------|------|------|
| `draft` | 草稿 | 登记员创建后未提交，可编辑和提交 |
| `pending_review` | 待审核 | 已提交，等待主管审核 |
| `review_passed` | 审核通过待复核 | 主管通过，等待复核负责人归档 |
| `review_rejected` | 审核驳回 | 主管驳回，登记员需补正后重提 |
| `review_returned` | 复核退回 | 复核负责人退回，登记员需补正后重提 |
| `review_approved` | 已归档 | 全部流程完成，不可再修改 |

## 核心特性

### 三角色权限隔离
- 后一岗位不能替前一岗位补流程
- 每个角色只能执行权限范围内的操作
- 后端中间件严格校验角色权限

### 批量操作
- 支持选中多条任务批量审核/复核
- 逐条处理、逐条返回结果
- 结果分类：成功 / 失败 / 需重试
- 每条结果附带具体原因说明

### 后端强校验
- **角色校验**: 错角色操作直接拦截，返回具体原因
- **版本校验**: 旧版本提交返回版本冲突（乐观锁），需刷新后重试
- **证据校验**: 审核通过必须有过程核验证据，归档必须有复核证据
- **状态校验**: 不符合当前状态的操作直接拦截，标注具体原因
- **证据角色限制**: 登记证据仅登记员可上传；过程核验证据仅主管可上传；复核证据仅复核负责人可上传

### 证据三类型

| 证据类型 | 值 | 上传角色 | 可上传状态 |
|----------|-----|----------|------------|
| 登记证据 | `registration` | 采样登记员 | 草稿 / 驳回 / 退回 |
| 过程核验证据 | `process` | 采样审核主管 | 待审核 |
| 复核归档证据 | `review` | 复核负责人 | 审核通过待复核 |

### 后端 API 端点（绕过页面时的校验）

| 端点 | 方法 | 角色 | 校验项 |
|------|------|------|--------|
| `/api/batch/registrar-submit` | POST | registrar | 版本冲突、状态必须是草稿/驳回/退回、缺登记证据 |
| `/api/batch/supervisor-review` | POST | supervisor | 版本冲突、状态必须是待审核、缺过程证据（通过时）、驳回原因必填 |
| `/api/batch/reviewer-review` | POST | reviewer | 版本冲突、状态必须是审核通过、缺复核证据（归档时）、退回原因必填 |
| `/api/tasks/:id/evidences` | POST | 全部 | 角色与证据类型匹配、状态是否允许上传该类型 |

## API 响应格式

所有接口统一返回格式：

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

- `code = 0` 表示成功
- `code != 0` 表示失败，`message` 为错误原因
