# 会员服务单管理系统

会员服务单管理系统，支持会员服务单登记、过程核验、复核归档全流程管理。

## 技术栈

- **前端**: Preact + Vite (端口 3005)
- **后端**: Go + Gin (端口 8005)
- **数据库**: SQLite

## 快速开始

### 启动后端

```bash
cd backend
go mod tidy
go run ./cmd/server
# 或编译运行
go build -o bin/server ./cmd/server
./bin/server
```

后端服务启动在 `http://localhost:8005`

### 启动前端

```bash
cd frontend
npm install
npm run dev
```

前端服务启动在 `http://localhost:3005`

## 角色说明

系统支持三种角色切换（页面右上角可切换角色）：

1. **会员服务登记员** (registrar) - 李登记
   - 创建会员服务单登记
   - 上传/补充附件材料
   - 提交审核
   - 处理退回补正

2. **会员服务审核主管** (auditor) - 王审核
   - 接收待审核工单
   - 审核附件材料
   - 审核通过/退回补正/驳回
   - 填写处理结果

3. **口腔连锁门诊复核负责人** (reviewer) - 张复核
   - 接收待复核工单
   - 复核归档
   - 退回补正

## 服务单状态流转

```
登记员创建 → 待审核(pending) → 审核主管处理(processing) → 待复核(review) → 复核负责人归档(completed)
                         ↓                    ↓
                     退回补正(supplement)        退回(returned)
                         ↓
                      重新提交
                         ↓
                   回到待审核
```

## 功能说明

### 列表页
- 按状态筛选（全部/待审核/待补正/审核中/待复核/已完成/已驳回/已退回）
- 关键词搜索（单号/姓名/手机号）
- 统计卡片展示

### 详情页
- **基本信息**：会员信息、服务信息、服务说明
- **附件材料**：查看、上传、审核通过/驳回、删除重传
- **处理结果**：查看审核结果、审计备注
- **操作记录/审计**：完整的操作日志，记录谁、什么时候、做了什么操作、状态变更

### 附件管理
- 补齐附件后才能回到处理队列
- 被驳回的附件保留驳回原因
- 附件审核记录进审计日志

### 审计追踪
- 所有操作均有审计日志
- 记录操作人、角色、时间、操作内容
- 状态变更记录
- 失败/驳回/退回原因均有记录

## API 接口

### 订单相关
- `GET /api/orders` - 获取订单列表
- `GET /api/orders/:id` - 获取订单详情
- `POST /api/orders` - 创建订单
- `POST /api/orders/:id/process` - 处理订单

### 附件相关
- `GET /api/attachments/order/:orderId` - 获取订单附件
- `POST /api/attachments/order/:orderId/upload` - 上传附件
- `POST /api/attachments/:id/reject` - 驳回附件
- `POST /api/attachments/:id/approve` - 通过附件
- `DELETE /api/attachments/:id` - 删除附件

### 用户相关
- `GET /api/users` - 获取用户列表
- `GET /api/users/current` - 获取当前用户

## 注意事项

- 数据库文件：`backend/data/member_service.db`
- 首次启动自动创建数据库和种子数据
- 删除数据库文件后重启服务会重新初始化
- 前端通过 Vite 代理转发 API 请求到后端
- CORS 已配置放行前端端口 3005
