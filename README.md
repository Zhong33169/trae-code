# 宠物医院住院护理管理系统

## 技术栈

- 前端：Vue 3 + Vite（端口 3004）
- 后端：Node.js + Express（端口 8004）
- 数据库：SQLite（本地文件，初始化即含演示数据）

## 快速启动

```bash
# 1. 安装后端依赖并初始化数据
cd backend
npm install
node src/init-db.js   # 初始化数据库和演示数据（仅需执行一次）
npm run dev           # 启动后端，监听 http://localhost:8004

# 2. 安装前端依赖并启动
cd ../frontend
npm install
npm run dev           # 启动前端，监听 http://localhost:3004
```

打开浏览器访问 http://localhost:3004

## 核心功能

### 角色工作流

护理单状态流转严格按角色区分，不同角色看到的操作按钮不同（不仅是隐藏，后端也做权限校验）：

- **医生**（发起）：创建护理单 → 推进到「办理中」
- **护士**（办理）：添加用药记录、上传附件、标记补传 → 推进到「复核中」
- **复核员**（复核归档）：审核附件（通过/驳回）、确认出院、退回护理单 → 归档

状态流转：`已发起 → 办理中 → 复核中 → 已归档`（退回可发生在办理中/复核中阶段）

### 附件管理

- 每个附件标记：**必传/非必传**、**初始上传/补传/重新提交**、**待审核/已通过/已驳回**
- 被驳回的附件显示驳回原因，补传的附件显示补传原因
- 重新提交的附件可追溯到被替换的原附件
- 补正痕迹在审计日志中完整记录，可倒查

### 审计日志

所有操作均记录审计日志，包含：
- 操作人（姓名、角色）
- 操作时间
- 操作类型（创建、状态变更、上传、审核、驳回、补传、退回、超时等）
- 变更前后值
- 失败/退回/驳回原因

审计日志页面支持按操作类型、角色、时间范围、关键词筛选。

## API 端点

| 端点 | 方法 | 说明 |
|------|------|------|
| /api/users | GET | 获取用户列表 |
| /api/users/login | POST | 用户登录 |
| /api/care-records | GET | 护理单列表（支持筛选） |
| /api/care-records/stats/summary | GET | 护理单统计 |
| /api/care-records/:id | GET | 护理单详情（含附件、用药、出院、审计） |
| /api/care-records | POST | 创建护理单 |
| /api/care-records/:id | PUT | 更新护理单 |
| /api/care-records/:id/status | PUT | 更新护理单状态 |
| /api/medications/:careRecordId | GET/POST | 用药记录 |
| /api/discharge/:careRecordId | GET/POST | 出院确认 |
| /api/discharge/:id/confirm | PUT | 确认/驳回出院 |
| /api/attachments/:careRecordId | GET | 附件列表 |
| /api/attachments/:careRecordId/upload | POST | 上传附件 |
| /api/attachments/:id/review | PUT | 审核附件 |
| /api/attachments/:id/supplement | PUT | 标记补传 |
| /api/audit/care-record/:careRecordId | GET | 单条护理单审计日志 |
| /api/audit | GET | 全局审计日志（支持筛选） |
