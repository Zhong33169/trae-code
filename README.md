# 需求跟踪单系统

一个基于 Nuxt 3 + Fastify + SQLite 的需求跟踪单管理系统，支持需求反馈、产品评审、发布回访全流程管理，以及离线台账回填、审计日志等功能。

## 技术栈

- **前端**: Nuxt 3 + Vue 3 + TypeScript + @nuxt/ui
- **后端**: Node.js + Fastify
- **数据库**: SQLite (better-sqlite3)
- **前端端口**: 3003
- **后端端口**: 8003

## 快速开始

### 1. 后端启动

```bash
cd backend
npm install
npm run init-db   # 初始化数据库（首次运行）
npm start         # 启动服务，端口 8003
```

### 2. 前端启动

```bash
cd frontend
npm install
npm run dev       # 启动开发服务，端口 3003
```

### 3. 访问系统

打开浏览器访问: http://localhost:3003

## 角色说明

系统包含三种角色，可在页面右上角切换：

| 角色 | 用户名 | 说明 |
|------|--------|------|
| 需求跟踪登记员 | registrar1 (张登记) | 创建需求单、提交审核、补正退回的需求单、离线台账导入 |
| 需求跟踪审核主管 | auditor1 (李审核) | 审核需求单、产品评审、发布管理 |
| SaaS客户成功团队复核负责人 | reviewer1 (王复核) | 复核归档、审计备注 |

## 功能说明

### 1. 需求反馈阶段
- 登记员创建需求单（草稿状态）
- 登记员提交审核
- 审核主管审核通过 → 进入产品评审阶段
- 审核主管退回补正 → 退回给登记员修改
- 审核主管标记材料缺失 → 标记为异常单

### 2. 产品评审阶段
- 审核主管进行产品评审
- 评审通过 → 进入发布回访阶段
- 评审不通过 → 标记为异常单

### 3. 发布回访阶段
- 审核主管发布需求
- 审核主管申请复核
- 复核负责人复核归档
- 可添加审计备注

### 4. 离线台账回填
- 支持批量导入离线台账数据
- 记录导入批次、来源
- 自动检测差异和冲突
- 状态冲突时不静默覆盖，保留冲突记录
- 导入结果逐条说明（成功/失败/冲突）

### 5. 审计日志
- 记录所有操作的审计日志
- 失败原因单独记录
- 可追溯谁、什么时候、为什么操作失败
- 支持按失败状态、关键词筛选

## API 接口

### 用户相关
- `GET /api/users` - 获取所有用户
- `GET /api/users/current` - 获取当前用户

### 需求单相关
- `GET /api/tickets` - 获取需求单列表（支持 stage, status, is_abnormal, keyword 筛选）
- `GET /api/tickets/:id` - 获取需求单详情
- `POST /api/tickets` - 创建需求单
- `PUT /api/tickets/:id` - 更新需求单
- `POST /api/tickets/:id/submit` - 提交审核
- `POST /api/tickets/:id/audit-pass` - 审核通过
- `POST /api/tickets/:id/reject` - 退回
- `POST /api/tickets/:id/review-pass` - 评审通过
- `POST /api/tickets/:id/review-reject` - 评审不通过
- `POST /api/tickets/:id/release` - 发布
- `POST /api/tickets/:id/request-review` - 申请复核
- `POST /api/tickets/:id/archive` - 复核归档

### 导入相关
- `GET /api/import-batches` - 获取导入批次列表
- `GET /api/import-batches/:id` - 获取导入批次详情
- `POST /api/import-batches` - 新建导入批次

### 审计日志
- `GET /api/audit-logs` - 获取审计日志

### 其他
- `GET /api/dashboard/stats` - 仪表盘统计
- `GET /api/status-options` - 获取状态选项

## 设计要点

### 状态流转
- 需求跟踪单一进入系统就能通过状态标签识别状态
- 颜色区分: 灰色(草稿/归档)、蓝色(进行中)、绿色(通过)、橙色(退回)、红色(失败/缺失/超时)

### 角色权限
- 按钮根据角色和状态显示/隐藏，不是只在前端藏按钮
- 后端也做了角色校验，无权限操作会返回 403

### 异常标记
- is_abnormal 字段标记是否异常
- abnormal_type 记录异常类型 (material_missing / returned / overdue / review_rejected)
- 列表页支持按异常筛选

### 离线回填
- 记录导入批次号、来源
- 每条记录有差异说明
- 状态冲突时不静默覆盖，保留冲突记录
- 冲突也会写入审计日志

### 审计追踪
- 所有操作都有审计日志
- 失败操作记录失败原因
- 可追溯操作人、角色、时间、详情
