# 产业园物业-异常申诉复核企业报修单系统

企业报修单从登记到复核归档全流程处理系统，支持异常申诉的提交、受理、驳回补正和再次提交。

## 技术栈

- **前端**：Next.js 14 App Router + Tailwind CSS（端口 3009）
- **后端**：Python Starlette + aiosqlite（端口 8009）
- **数据库**：SQLite 本地文件（`backend/data.db`）

## 快速开始

### 1. 环境要求

- Python 3.10+
- Node.js 18+

### 2. 安装后端依赖

```bash
cd backend
pip install -r requirements.txt
```

### 3. 安装前端依赖

```bash
cd frontend
npm install
```

### 4. 初始化数据库并启动后端

```bash
cd backend
python app.py --seed
```

`--seed` 参数会在首次启动时写入样例数据（3 个用户 + 8 条工单）。数据库文件自动创建为 `backend/data.db`。如需重置数据，删除 `data.db` 后重新执行即可。

### 5. 启动前端

```bash
cd frontend
npm run dev
```

### 6. 访问系统

浏览器打开 http://localhost:3009

## 端口配置

| 服务 | 默认端口 | 修改方式 |
|------|---------|---------|
| 前端 | 3009 | 修改 `frontend/package.json` 中 `dev` 脚本的 `-p` 参数，或 `npm run dev -- -p 自定义端口` |
| 后端 | 8009 | `python app.py --port 自定义端口`，或设置环境变量 `PORT=自定义端口` |

修改后端端口后，需同步设置前端环境变量：

```bash
NEXT_PUBLIC_API_URL=http://localhost:自定义端口/api npm run dev
```

## 角色与流程

### 三个角色

| 角色 | 用户名 | 职责 |
|------|-------|------|
| 登记员 | 张登记 | 发起工单、补正后重新提交 |
| 审核主管 | 李主管 | 受理审核、审核通过/退回补正/驳回 |
| 复核负责人 | 王复核 | 受理复核、归档/退回 |

### 工单状态流转

```
草稿 ──[登记员提交]──→ 已提交 ──[主管受理]──→ 审核中 ──[主管通过]──→ 审核通过 ──[复核受理]──→ 复核中 ──[归档]──→ 已归档
                          │                    │                                          │
                          │                    └──[退回补正]──→ 已退回 ──[登记员补正提交]──→ 已提交  │
                          │                    │                                          │
                          │                    └──[驳回]──→ 已驳回                          └──[退回]──→ 已退回
```

### 后端校验规则

提交工单时后端会校验：
- 当前处理人是否匹配
- 操作人角色是否正确
- 工单状态是否允许该操作
- 版本号是否一致（乐观锁）
- 退回工单必须补充证据描述

校验不通过时保留原状态并写入 `validation_failed` 操作记录。

## API 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/users | 获取用户列表 |
| GET | /api/stats | 获取各状态工单统计 |
| GET | /api/orders | 工单列表（支持 status/handler_role/keyword/offset/limit 参数） |
| GET | /api/orders/{id} | 工单详情（含操作记录） |
| POST | /api/orders | 创建工单 |
| PUT | /api/orders/{id} | 编辑工单（仅草稿/退回状态） |
| POST | /api/orders/{id}/submit | 提交工单 |
| POST | /api/orders/{id}/accept_review | 受理审核 |
| POST | /api/orders/{id}/review | 审核操作（result: approve/return/reject） |
| POST | /api/orders/{id}/accept_recheck | 受理复核 |
| POST | /api/orders/{id}/recheck | 复核操作（result: archive/return） |

## 演示操作指南

1. 打开系统后，点击右上角选择用户身份（张登记/李主管/王复核）
2. 在首页查看各状态工单统计
3. 进入工单列表，可按状态/角色/关键词筛选
4. 点击工单编号进入详情页：
   - 查看基本信息、历史处理意见、操作记录时间线
   - 根据当前角色和工单状态进行相应操作
5. 切换不同用户角色体验完整流程：
   - 选张登记 → 新建工单并提交
   - 选李主管 → 受理审核并做出审核决定
   - 选王复核 → 受理复核并归档或退回
