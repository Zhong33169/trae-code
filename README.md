# 畜牧养殖场-移动补录校验养殖巡检单系统

## 系统概述

本系统用于畜牧养殖场的养殖巡检单管理，支持三角色工作流审批、移动补录校验、证据链追踪和批量操作。

## 角色与工作流

| 角色 | 用户名 | 职责 |
|------|--------|------|
| 养殖巡检登记员 | `zhangsan` | 发起/补正巡检单、补录修正 |
| 养殖巡检审核主管 | `lisi` | 审核、通过/驳回/退回 |
| 畜牧养殖场复核负责人 | `wangwu` | 复核归档/退回 |

**工作流**: 草稿 → 已提交 → 审核中 → 已审核 → 已归档

后一个岗位不能替前一个岗位操作，错角色提交会被后端拦截并返回具体原因。

## 快速启动

### 1. 后端启动

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install "litestar[standard]>=2.0" "pydantic>=2.0"
rm -f inspection.db
uvicorn app:app --host 0.0.0.0 --port 8007
```

后端启动时自动初始化 SQLite 数据库和样例数据。

### 2. 前端启动

```bash
cd frontend
npm install
npm run dev
```

前端运行在 `http://localhost:3007`，请求自动代理到后端 `http://localhost:8007`。

### 3. 演示账号

| 用户名 | 角色 | 说明 |
|--------|------|------|
| zhangsan | 登记员 | 创建巡检单、补录、提交 |
| lisi | 审核主管 | 开始审核、通过/驳回/退回 |
| wangwu | 复核负责人 | 复核归档、退回 |

在页面顶部角色切换按钮即可快速切换身份。

## 后端校验规则

绕过页面直接提巡检单会被以下规则拦截：

1. **错角色**: 登记员不能审核，审核主管不能创建，复核负责人不能提交
2. **旧版本**: 提交版本号与当前版本不一致，返回版本冲突
3. **缺证据**: 提交至少需2条证据，审核至少需1条，归档至少需1条
4. **错状态**: 只能对当前状态允许的操作执行，如不能对草稿直接审核
5. **重复补录**: 同一字段相同新值不能重复补录
6. **补录原因**: 补录原因不能少于2个字符
7. **补录状态**: 只有草稿/退回状态才能补录

所有校验失败都返回具体中文原因。

## API 接口

- `GET /api/users` - 用户列表
- `POST /api/login` - 登录
- `GET /api/tickets` - 巡检单列表（支持 status/pen_id/role 筛选）
- `GET /api/tickets/{id}` - 巡检单详情（含所有关联数据）
- `POST /api/tickets` - 创建巡检单
- `PUT /api/tickets/{id}` - 修改巡检单
- `POST /api/tickets/{id}/action` - 流程操作
- `POST /api/tickets/{id}/supplement` - 补录
- `POST /api/tickets/batch-action` - 批量操作
- `POST /api/tickets/{id}/evidence` - 添加证据
- `GET /api/stats` - 统计数据

## 技术栈

- 前端: Lit + Vite (端口 3007)
- 后端: Python + Litestar + SQLite (端口 8007)
- CORS: 后端放行 `http://localhost:3007`
