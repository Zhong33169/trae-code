# 水务营业厅抢修工单到期预警处置系统 PRD

## 1. 产品概述

面向水务营业厅的抢修工单到期预警处置系统，覆盖窗口人员建单、抄表主管推进、营业经理复核归档三段式流转，并以到期预警（临期/逾期分级）驱动处置优先级。系统用"列表—详情—后端校验"三件套替代空壳管理页，确保工单仅在权限正确、顺序合法、证据齐全、无并发冲突时才能推进，杜绝静默推进。

- 目标用户：水务营业厅窗口人员、抄表主管、营业经理
- 解决问题：抢修工单流转无校验、到期预警与普通待办混排、并发提交导致状态错乱、越权/越序可静默推进
- 价值：让到期预警看得见、工单推进可控可审计、批量处置后状态与统计自洽

## 2. 核心功能

### 2.1 用户角色

| 角色 | 标识 | 负责阶段 | 核心权限 |
|------|------|----------|----------|
| 窗口人员 | window_staff | 抢修工单登记 | 建单、登记材料与时限、提交处理意见 |
| 抄表主管 | meter_supervisor | 过程核验 | 核验材料与时限，推进或退回工单 |
| 营业经理 | business_manager | 复核归档 | 终审复核，归档同步或退回 |

### 2.2 功能模块

1. **工单列表页**：岗位切换器、状态队列分组（待审核 / 审核通过 / 已同步）、到期预警分级（临期/逾期独立成列不混入普通待办）、批量处理动作
2. **工单详情页**：三阶段流转轨道、材料清单与时限校验、处理意见、到期预警档位（截止时间/剩余时间/档位）、审计时间线、阶段动作按钮
3. **到期预警看板**：临期队列与逾期队列独立展示、剩余时间倒计时、批量催办/处置

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 工单列表页 | 岗位切换器 | 顶部切换 window_staff / meter_supervisor / business_manager，切换后列表与可操作动作随岗位变化 |
| 工单列表页 | 统计概览 | 按"待审核/审核通过/已同步"统计数量，并叠加临期/逾期计数 |
| 工单列表页 | 状态队列 | 待审核、审核通过、已同步三列队列，每列展示工单卡片与可执行动作 |
| 工单列表页 | 到期预警分级 | 临期、逾期工单以独立标识与颜色突出，不与普通待办混排 |
| 工单列表页 | 批量处理 | 队列内多选 + 批量推进/退回，结果即时回显并刷新统计 |
| 工单详情页 | 三阶段轨道 | 登记 → 过程核验 → 复核归档 阶段轨道，高亮当前阶段 |
| 工单详情页 | 材料与时限 | 每阶段材料清单（必填/已提供）、时限校验、处理意见 |
| 工单详情页 | 到期预警档位 | 展示截止时间、剩余时间倒计时、命中的预警档位（正常/提醒/临期/逾期） |
| 工单详情页 | 阶段动作 | 提交登记、核验推进/退回、复核归档/退回，动作按钮随岗位与阶段显隐 |
| 工单详情页 | 审计时间线 | 记录创建/提交/推进/退回/同步等动作的操作人、角色、前后状态与版本 |
| 到期预警看板 | 临期队列 | 剩余时间≤24h 的工单，按剩余时间升序，支持批量处置 |
| 到期预警看板 | 逾期队列 | 已过截止时间工单，红色警示，支持批量处置 |

## 3. 核心流程

主流程：窗口人员建单登记 → 抄表主管过程核验（推进/退回）→ 营业经理复核归档（同步/退回）。每一步推进须经四重校验：权限、顺序、证据、并发，任一不满足则拒绝并返回明确原因，绝不静默推进。

```mermaid

    A -->|不通过| "拒绝并返回原因"
    "抄表主管过程核验" -->|"推进/退回"| B{"校验: 权限=抄表主管?
顺序=核验阶段?
登记已提交?
证据齐全?
无并发冲突?"}
    B -->|推进| "营业经理复核归档"
    B -->|退回| "窗口人员建单登记"
    "营业经理复核归档" -->|"同步/退回"| C{"校验: 权限=营业经理?
顺序=归档阶段?
```

到期预警流程：根据截止时间计算剩余时间，命中档位为：正常(>48h) / 提醒(24~48h) / 临期(≤24h) / 逾期(≤0h)。临期与逾期在列表与看板中独立成列，不混入普通待审核队列。

## 4. 用户界面设计

### 4.1 设计风格

- 设计方向：**水务调度蓝图控制台**。以工程蓝图纸质感为底，深水青色为主，辅以警戒色，营造可信赖的运营调度气质，区别于通用后台"白底紫渐变"AI 风格。
- 主色：深水青 #0E4D4D（主操作/品牌）；辅色：青蓝 #0EA5B7（链接/进度）
- 警戒色：琥珀 #D97706（临期/提醒）、朱红 #DC2626（逾期/退回）、翠绿 #059669（通过/同步）
- 中性：纸白 #F5F7F6 底、#FFFFFF 卡面、墨黑 #1A2B2B 文字
- 字体：标题用 Big Shoulders Display（高耸工业感）、正文用 Manrope、数据/工单号/时间戳用 JetBrains Mono
- 按钮：直角偏小圆角(4px)，实色填充主操作，描边次操作，警戒色用于退回/逾期
- 布局：桌面优先，左侧主工作区三列队列，顶部岗位与统计条，详情用阶段轨道 + 双栏（左流程右审计）
- 图标：lucide-react 线性图标

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 要素 |
|----------|----------|---------|
| 工单列表页 | 顶部操作条 | 岗位切换分段控件、统计胶囊、刷新按钮，蓝图网格底纹 |
| 工单列表页 | 状态队列 | 三列卡片墙（待审核/审核通过/已同步），卡片含工单号、类型、剩余时间倒计时、预警档位色条 |
| 工单列表页 | 批量处理条 | 多选后浮出批量动作条，显示选中数与动作按钮 |
| 工单详情页 | 阶段轨道 | 三段进度轨道，当前段高亮深水青，已完成段翠绿，未达段灰 |
| 工单详情页 | 到期预警卡 | 大字号剩余时间倒计时 + 档位徽章 + 截止时间，按档位变色 |
| 工单详情页 | 材料清单 | 必填材料勾选状态，缺失项红字标注 |
| 工单详情页 | 审计时间线 | 右侧纵向时间线，含角色徽章与前后状态 |
| 到期预警看板 | 临期/逾期分栏 | 双栏红黄对比，剩余时间进度条 |

### 4.3 响应式

桌面优先（1280+ 为基准），列表三列在窄屏折叠为单列滚动；详情页双栏在窄屏堆叠。触摸目标≥40px。

### 4.4 动效

- 页面加载：列表卡片错峰淡入上移（animation-delay 阶梯）
- 阶段切换：轨道填充过渡、剩余时间倒计时数字脉冲（临期/逾期时）
- 操作反馈：批量处理结果 Toast，状态变更卡片平滑位移到目标队列
- 预警：逾期卡片左侧朱红色条呼吸闪烁
