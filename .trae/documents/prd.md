## 1. 产品概述

酒店集团移动补录校验住客订单系统，用于规范住客订单从补录登记→过程核验→复核归档的全流程，通过角色权限隔离和证据校验机制，防止越权操作、重复补录、缺失证据和覆盖已归档结果。

- 目标用户：酒店前厅接待、客房主管、值班经理
- 核心价值：确保补录流程合规可追溯，关键证据不可缺失，操作不可越权

## 2. 核心功能

### 2.1 用户角色

| 角色 | 登录方式 | 核心权限 |
|------|----------|----------|
| 前厅接待 | 账号密码 | 创建订单、补录登记、提交待核验 |
| 客房主管 | 账号密码 | 过程核验、补充核验证据、提交待复核 |
| 值班经理 | 账号密码 | 复核归档、退回重做、最终归档确认 |

### 2.2 功能模块

1. **订单队列主页**：住客订单列表、状态筛选、角色切换、侧栏证据面板、批量操作
2. **订单详情办理页**：补录登记/过程核验/复核归档的操作表单、证据上传、校验提示

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 订单队列主页 | 订单列表区 | 按状态/角色筛选订单，显示订单号、住客、状态、关键证据摘要 |
| 订单队列主页 | 侧栏证据面板 | 选中订单后展示登记证据、核验证据、归档证据的关键摘要 |
| 订单队列主页 | 角色切换 | 顶部切换当前角色，筛选和操作按钮随角色联动更新 |
| 订单队列主页 | 批量操作区 | 批量提交核验/批量复核归档，校验通过后执行 |
| 订单详情办理页 | 补录登记表单 | 前厅接待填写住客信息、补录原因、上传登记证据 |
| 订单详情办理页 | 核验办理表单 | 客房主管核验补录内容，上传核验证据，标记通过/退回 |
| 订单详情办理页 | 归档办理表单 | 值班经理最终复核，确认归档或退回，上传归档证据 |
| 订单详情办理页 | 校验提示区 | 实时显示校验失败原因（缺证据、错角色、旧版本等） |

## 3. 核心流程

住客订单从创建到归档经历三个阶段，每个阶段由对应角色操作，不可越权推进：

1. 前厅接待创建订单并补录登记信息，上传登记证据，提交至「待核验」
2. 客房主管核验补录内容，上传核验证据，通过则推进至「待复核」，退回则回退至「待补录」
3. 值班经理复核归档，上传归档证据，确认归档则状态变为「已归档」，退回则回退至「待核验」

```mermaid
flowchart TD
    "创建订单" --> "待补录"
    "待补录" -->|"前厅接待 补录登记"| "待核验"
    "待核验" -->|"客房主管 核验通过"| "待复核"
    "待核验" -->|"客房主管 退回"| "待补录"
    "待复核" -->|"值班经理 归档确认"| "已归档"
    "待复核" -->|"值班经理 退回"| "待核验"
```

**校验规则**：
- 前厅接待不能替客房主管推进核验，客房主管不能替值班经理归档
- 重复补录同一订单被拦截
- 缺失必需证据时无法推进
- 已归档订单不可覆盖修改
- 提交时版本号不匹配（旧版本）被拦截
- 后端对所有规则强制校验，返回具体拦截原因

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深靛蓝(#1e3a5f) + 金色点缀(#d4a853)，传达酒店行业的高端与严谨
- 辅助色：白色/浅灰背景 + 状态色（绿/黄/红）
- 按钮：圆角8px，主操作按钮实心填充，次要操作描边
- 字体：Noto Sans SC，标题18-24px，正文14px，辅助12px
- 布局：左侧订单列表(60%) + 右侧证据面板(40%)，顶部角色切换栏
- 图标：lucide-react 图标库

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 订单队列主页 | 顶部栏 | 角色切换标签页、当前角色徽章、筛选下拉框 |
| 订单队列主页 | 订单列表 | 卡片式列表，每卡显示订单号、住客名、状态标签、证据完成度进度条 |
| 订单队列主页 | 侧栏证据面板 | 三栏折叠区（登记/核验/归档），每栏显示证据缩略和完成状态 |
| 订单队列主页 | 批量操作栏 | 底部固定栏，勾选订单后出现，显示批量操作按钮和校验提示 |
| 订单详情办理页 | 操作表单 | 分步骤表单，当前步骤高亮，证据上传区域带拖拽样式 |
| 订单详情办理页 | 校验提示 | 红色/黄色横幅提示，明确告知拦截原因和修复建议 |

### 4.3 响应式

- 桌面优先设计（1920/1440/1280px）
- 侧栏证据面板在窄屏下可折叠/抽屉式展示
