## 1. 产品概述

访客预约异常申诉复核系统，用于行政后勤中心对访客预约过程中出现的异常进行申诉登记、审核、复核归档的闭环管理。系统确保每一步操作都留有完整记录，详情中可追溯上一处理人的意见与结果，处理完成后队列、状态、统计数字同步变化。

- 目标用户：行政后勤中心人员（登记员、审核主管、复核负责人）
- 核心价值：异常申诉全流程可追溯、操作留痕、状态可控

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 访客预约登记员 | 系统预设 | 发起申诉、补正提交 |
| 访客预约审核主管 | 系统预设 | 审核办理（通过/驳回/退回补正） |
| 行政后勤中心复核负责人 | 系统预设 | 复核归档（通过/驳回/退回补正） |

### 2.2 功能模块

1. **申诉队列页**：按状态分 tab 展示待办/已办申诉列表，含统计数字
2. **申诉详情页**：展示申诉信息、操作记录时间线、当前处理表单
3. **申诉发起页**：登记员填写申诉表单并提交
4. **统计面板**：各状态数量汇总、角色视角待办计数

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 申诉队列页 | 状态标签页 | 按「待登记/待审核/待复核/已归档/全部」分 tab，各 tab 显示对应数量徽章 |
| 申诉队列页 | 申诉卡片列表 | 每条显示申诉编号、访客姓名、异常类型、当前状态、提交时间、当前处理人 |
| 申诉详情页 | 基本信息 | 申诉编号、访客姓名、预约日期、异常类型、描述、证据附件列表 |
| 申诉详情页 | 操作记录时间线 | 按时间倒序展示每步操作：操作人、角色、动作、意见、时间 |
| 申诉详情页 | 处理表单 | 根据当前角色和状态动态渲染：通过/驳回/退回补正，含意见输入框 |
| 申诉详情页 | 上一步信息 | 显示上一处理人的意见和处理结果 |
| 申诉发起页 | 发起表单 | 填写访客信息、异常类型、描述、上传证据，选择是否补正 |
| 统计面板 | 数字卡片 | 总数/待审核/待复核/已归档/退回补正的计数 |

## 3. 核心流程

访客预约异常申诉按三步流程流转：登记员发起/补正 → 审核主管办理 → 复核负责人复核归档。每一步操作均写入操作记录表，状态变更同步更新队列和统计。

```mermaid
flowchart TD
    "A[登记员发起申诉]" --> "B[状态: 待审核]"
    "B" --> "C{审核主管办理}"
    "C" -->|"通过"| "D[状态: 待复核]"
    "C" -->|"驳回"| "E[状态: 已驳回]"
    "C" -->|"退回补正"| "F[状态: 退回补正]"
    "F" -->|"登记员补正提交"| "B"
    "D" --> "G{复核负责人复核}"
    "G" -->|"通过归档"| "H[状态: 已归档]"
    "G" -->|"驳回"| "E"
    "G" -->|"退回补正"| "F"
    "E" -->|"登记员再次提交"| "B"
```

**状态枚举**：
- `pending_review` 待审核
- `pending_recheck` 待复核
- `returned` 退回补正
- `rejected` 已驳回
- `archived` 已归档

**异常类型**：
- 正常通过
- 缺证据
- 逾期
- 退回补正
- 状态冲突

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深靛蓝 (#1e3a5f)，辅助色：琥珀色 (#d97706) 用于警告/退回状态
- 按钮风格：圆角 (8px)，主要操作用实心色，次要操作用描边
- 字体：正文使用系统字体栈，标题使用 Noto Serif SC
- 布局：左侧导航 + 右侧内容区，顶部统计卡片
- 图标：lucide-react 图标库

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 申诉队列页 | 状态标签页 | 水平 tab 栏，各 tab 右侧带数字徽章 |
| 申诉队列页 | 申诉卡片列表 | 卡片式布局，左侧状态色条，右侧操作按钮 |
| 申诉详情页 | 操作记录时间线 | 垂直时间线，节点图标区分操作类型，悬停显示详情 |
| 申诉详情页 | 处理表单 | 底部固定操作栏，单选按钮组 + 文本域 |
| 统计面板 | 数字卡片 | 网格布局，大数字 + 小标签 |

### 4.3 响应式

桌面优先设计，最小宽度 1024px，内容区最大宽度 1280px 居中

### 4.4 3D 场景

不适用
