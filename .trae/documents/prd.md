## 1. 产品概述

公关传播团队-到期预警处理媒体邀约单系统，用于管理媒体邀约单从发起、审核到复核归档的全生命周期，核心解决"谁来处理"和"到期预警"问题，确保每张邀约单在时限内被正确推进，临期/逾期不被淹没在普通待办中。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 媒体邀约登记员 | 选择岗位进入 | 发起新邀约单、补正被退回的邀约单 |
| 媒体邀约审核主管 | 选择岗位进入 | 审核办理邀约单、退回补正、通过转复核 |
| 公关传播团队复核负责人 | 选择岗位进入 | 复核邀约单、归档、退回审核 |

### 2.2 功能模块

1. **工作台首页**: 按岗位展示待办队列（普通/临期/逾期三档）、统计卡片、快捷操作
2. **邀约单列表页**: 按岗位筛选、到期预警标签、批量操作、多维度筛选
3. **邀约单详情页**: 登记表单/审核表单/复核表单、材料附件、嘉宾确认、签到反馈、处理意见、操作日志
4. **审计记录页**: 全量操作日志、按单号/操作人/时间筛选

## 3. 核心流程

### 3.1 媒体邀约单生命周期

登记员发起邀约单 → 审核主管办理（通过/退回补正）→ 复核负责人复核（归档/退回审核）

- 登记员发起时必须填写：标题、媒体类型、活动信息、截止时间、至少一份材料附件
- 审核主管办理时必须填写处理意见；退回补正时需说明原因
- 复核负责人复核时必须确认嘉宾确认状态和签到反馈是否完整；归档需所有必要材料齐全
- 嘉宾确认未完成时，审核主管不能通过
- 签到反馈缺失时，复核负责人不能归档
- 材料不完整时，任何推进操作都会被拒绝
- 截止时间已过且未完成，标记为逾期

### 3.2 状态机

```mermaid
stateDiagram-v2
    [*] --> "草稿": 登记员发起
    "草稿" --> "待审核": 登记员提交
    "待审核" --> "审核退回": 审核主管退回补正
    "审核退回" --> "待审核": 登记员补正后重新提交
    "待审核" --> "待复核": 审核主管通过
    "待复核" --> "复核退回": 复核负责人退回审核
    "待复核" --> "已归档": 复核负责人归档
    "复核退回" --> "待审核": 审核主管重新办理
    "已归档" --> [*]
```

### 3.3 到期预警规则

- **普通**: 距截止时间 > 72小时
- **临期**: 距截止时间 ≤ 72小时且 > 0
- **逾期**: 距截止时间 ≤ 0

### 3.4 权限与安全规则

- 越权操作：非当前岗位对应的待办不能操作，后端强制校验
- 顺序校验：状态必须按流程推进，不能跳步
- 证据校验：材料、嘉宾确认、签到反馈缺失时阻止推进
- 并发保护：乐观锁，同一条邀约单同时只能被一人操作成功

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深蓝(#1e3a5f) + 琥珀色(#d97706)作为预警强调色
- 辅助色：红色(#dc2626)用于逾期、绿色(#16a34a)用于已完成
- 按钮：圆角8px，主操作实色填充，次要操作描边
- 字体：思源黑体/系统默认无衬线体，标题18px、正文14px、辅助12px
- 布局：顶部导航栏 + 左侧岗位切换 + 右侧内容区
- 图标：使用lucide-react图标库

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 工作台首页 | 统计卡片 | 四宫格卡片，各状态数量+图标，临期/逾期卡片带强调色 |
| 工作台首页 | 待办队列 | 三色分区列表，每条显示单号、标题、剩余时间倒计时标签 |
| 邀约单列表页 | 列表区 | 表格布局，到期预警列显示红/橙/绿色标签，勾选框用于批量操作 |
| 邀约单详情页 | 表单区 | 分步展示当前岗位可编辑区域，灰色只读区域显示其他岗位已填信息 |
| 邀约单详情页 | 时限区 | 顶部横幅，倒计时数字醒目，逾期时整条红色背景闪烁 |
| 审计记录页 | 日志列表 | 时间线布局，每条显示操作人头像、动作描述、时间戳 |

### 4.3 响应式

桌面优先，最小宽度1024px，表格在小屏可横向滚动
